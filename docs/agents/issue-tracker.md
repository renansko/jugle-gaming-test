# Issue tracker: Local Markdown

Issues and PRDs for this repository live in `.scratch/`.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`
- The feature PRD is `.scratch/<feature-slug>/PRD.md`
- Implementation issues use `.scratch/<feature-slug>/issues/<NN>-<slug>.md`.
- Issue status is recorded near the top as `Status:`.
- Comments and execution evidence append under `## Comments`.

When a skill says to publish an issue, create a markdown file in the feature
directory and update the local index if one exists. No external tracker is
required.
