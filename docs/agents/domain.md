# Domain documentation

This repository uses a single domain context.

Before exploring a documented area, read `docs/brain/index.md`, then the
related Brain pages. Read `ARCHITECTURE.md` for system-wide decisions.

There is no root `CONTEXT.md`, `CONTEXT-MAP.md` or `docs/adr/` directory at
present. If one is added, it becomes part of the relevant context for future
engineering work.

Keep domain terms aligned with the Brain glossary and update the Brain and
`docs/brain/log.md` when behavior, contracts or integrations change.
