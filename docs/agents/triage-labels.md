# Triage labels

The local tracker uses the canonical labels below:

| Role | Label | Meaning |
| --- | --- | --- |
| Needs evaluation | `needs-triage` | Maintainer must evaluate the issue. |
| Needs information | `needs-info` | Waiting for missing context. |
| Agent-ready | `ready-for-agent` | Fully specified for AFK execution. |
| Human-ready | `ready-for-human` | Requires a human decision or action. |
| Won't fix | `wontfix` | Will not be actioned. |

Labels are written in the issue front matter or `Status:` metadata.
